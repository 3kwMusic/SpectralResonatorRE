# 验证范围与限制

1.5.0 的本地工程验证覆盖数值安全、生命周期、参数映射、MIDI 和自动化队列。已完成 Release VST3/Standalone 构建、pluginval 严格级别 7，以及多实例长时间稳定性验证。独立 Steinberg validator 未配置，不能记为已通过。

源码上传版的代码令牌与冻结的音频实现一致，只整理源码注释、构建依赖定位和文档。上传前重新运行 Release 构建、真实 processBlock 回归和 pluginval7。机器相关日志不随仓库发布。

稳定性测试通过不表示所有工作负载满足实时预算。最高谐波/声部、每采样点混合自动化、多实例叠加场景仍可超过块时限；此限制未在本次上传中优化。宿主提供的全局音阶/调律由本地 Scale/Root 控制替代，不保证任意宿主上下文同步。

默认值测试覆盖全部 28 项 APVTS 启动值与 reset-to-default 元数据。它不会强制覆盖已有工程或用户保存的默认状态。与其他产品的同输入听感对照由用户另行进行，不包含在此验证声明中。
