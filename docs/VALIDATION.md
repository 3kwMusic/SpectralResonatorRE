# 验证范围

## 1.5.4（2026-11-02）

- Windows x64 Release VST3 / Standalone 构建通过。
- 40 个回归入口通过，覆盖参数、整数曲线、自动化、MIDI、声部、生命周期、随机调制、频谱处理、静默唤醒和延后尾音。
- baseline 调用真实 `processBlock()`，验证冲激、干湿、衰减、阻尼、MIDI、采样率、状态和实际 VST3 延迟。
- 音频回调 C++ `new` 计数为零；此计数不涵盖直接 malloc、Windows Heap 或另载 DLL。
- pluginval 严格级别 7 通过；未配置独立 Steinberg validator。
- 系统安装版与验证产物 SHA-256 一致；用户已完成本轮手动核对。

发布文件的逐项 SHA-256 保存在发行包 `BINARY_MANIFEST.json`；两个 ZIP 的校验值见 `SHA256SUMS.txt`。源码归档同时保存项目及 JUCE 文件清单。

仓库可复跑的公共回归见 [开发说明](DEVELOPMENT.md)。40 入口是工程内专项测试的结果，不表示公共基线测试本身有 40 个入口。

## 覆盖限制

没有原版同输入自动音频 A/B，不声明逐样本或听感完全一致。内部宿主活动描述与 VST3 的适配存在边界，未采集原版完整 transport 轨迹。

高声部、高谐波数、多个实例和逐采样密集自动化可超出实时预算；历史极限压力测试存在实时预算失败，不作跨机器硬实时保证。1.5.0 的长时间压力结果不扩大为 1.5.4 完整长测。
