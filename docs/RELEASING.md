# 发布说明

当前仅维护源码，尚未发布二进制。未来发布前：

1. 同步版本、完成代码来源与第三方许可核对，保留版权和 SPDX 声明。
2. 构建 Release，运行真实 processBlock 回归及 pluginval 严格级别 7，核对实际插件路径。
3. 检查待上传文件与全部可达 Git 历史：不包含凭据、私人邮箱、本机绝对路径、AI 指令、内部研究记录、原厂程序或第三方音频素材。
4. 使用 GitHub 隐私邮箱提交，审核后创建对应标签。
5. 分发二进制时同时提供完整对应源码（包括实际使用的 JUCE 及构建所需依赖）、许可证、第三方声明、构建步骤和 SHA-256。GitHub 自动生成的源码 ZIP 不包含外部 JUCE，不能单独作为完整对应源码包。

标准 AGPL 允许商业使用和收费分发，不附加禁售或禁止商用条款。许可不替代第三方权利核查；普通音频作品不因使用本效果器而受到软件许可约束。

仓库可见性单独管理，提交、构建或发布标签均不自动改变其可见性。
